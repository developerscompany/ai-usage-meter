AI Usage Meter puts the limits of your AI coding tools on Stream Deck keys, so you see what's left before you hit a limit. One plugin for Claude, Codex and Kimi Code.

33 keys:
• All Services: Claude, Codex and Kimi side by side on one key
• Claude: 5-Hour Limit and Weekly Limit (all models or just Fable, Opus, Sonnet or Haiku), Both Limits, Peak Hours, Cloud Credit, API Credit, Extra Usage, Token Usage, API Cost, Cache Hits, Model Mix, Session Context, Streak, Claude Status, Launch Claude Code
• Codex: 5-Hour Limit, Weekly Limit, Both Limits, Credits, Token Usage, API Cost, Cache Hits, Model Mix, Codex Status, Launch Codex
• Kimi Code: 5-Hour Limit, Weekly Limit, Both Limits, Monthly Limit, Extra Usage, Kimi Status, Launch Kimi Code

Ten display styles (ring, gauge, battery, history and more) with live previews, your own yellow and red levels, several Claude Code accounts, and the logo of its service on every key (or none).

Requirements: for each service you use, its tool signed in on this computer: Claude Code (Pro or Max plan), Codex with a ChatGPT account, the Kimi Code app or a Kimi Code API key. Token, cost, cache and streak keys read the local logs of Claude Code and Codex. The API Credit key needs a Claude Console Admin API key.

Privacy: everything runs on your computer and nothing is collected. The plugin only reads the logins and logs of your tools, and talks only to the services themselves (api.anthropic.com, chatgpt.com, Kimi's API) and their public status pages.
